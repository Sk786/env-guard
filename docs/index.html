Features

Everything you need, nothing you don't

A focused tool that does one thing well — making your current environment impossible to miss.

🌈

Color-coded borders

A bold border wraps your entire browser window in the color you choose for each environment.

⚙

Flexible URL rules

Match URLs using wildcards or full regular expressions. One rule can cover an entire domain or a single path.

👥

Built-in environments

Production, Staging, QA, Development, or Custom — pick the label that fits and pair it with any color.

↔

Adjustable border width

Dial the border thickness from 1 to 20 px per rule so it's visible without being distracting.

🔒

100% local & private

All rules are stored in Chrome's sync storage. No servers, no telemetry, no data ever leaves your device.

⚡

Instant updates

Changes apply immediately — no page reload required. Add a rule and the border appears right away.

How it works

Up and running in under a minute

Three steps and you will never accidentally run a command against production again.

1

Install the extension

Add Env Guard from the Chrome Web Store. No account or sign-up required.

2

Add a URL rule

Click the toolbar icon, enter a URL pattern or regex, pick an environment, choose a color and border width.

3

Stay aware

Visit any matching URL and the color border appears immediately — a clear, persistent visual signal.
