Privacy Policy

Last updated: March 2026  ·  Effective immediately upon installation

Overview

Env Guard is designed with privacy as a first principle. The extension does not collect, transmit, or share any personal data, browsing history, or usage information. There are no analytics, no tracking pixels, and no external servers.

Data stored

The only data Env Guard stores are the rules you create — each rule consists of:

  • A URL pattern or regular expression you provide
  • An environment label (e.g. Production, Staging)
  • A border color (hex value)
  • A border width (number in pixels)

This data is saved exclusively in Chrome's built-in chrome.storage.sync API. It is synced across your own Chrome profile by Google if you are signed in to Chrome. Env Guard itself has no access to, and never reads or transmits, this synced data — it is handled entirely by the browser.

Permissions explained

Env Guard requests the following permissions, each with a specific and limited purpose:

  • storage — to save and retrieve your environment rules using chrome.storage.sync.
  • tabs — to detect the URL of the currently active tab so the correct border color can be applied immediately after you save or delete a rule. The extension does not read page content or tab titles.
  • scripting — to send a message to the content script on the active tab, triggering an update of the visual border. No scripts are injected beyond what is already declared in the extension.
  • host permissions (<all_urls>) — because environment rules can match any domain including internal tools, staging servers, or custom production URLs. The extension only reads the page URL to match against your rules. It does not read, modify, or send any page content.

No data collection

Env Guard does not:

  • Collect or transmit any personal information
  • Track your browsing history or visited URLs
  • Use analytics or telemetry of any kind
  • Contact any external server or third-party service
  • Display advertisements
  • Monetize your data in any way

Third-party services

Env Guard uses no third-party libraries, CDNs, or services at runtime. The extension is entirely self-contained.

Open source

Env Guard is open source. You can review the full source code on GitHub to verify these claims independently.

Changes to this policy

If this policy ever changes, the updated version will be posted at this URL and the "Last updated" date above will be revised. Continued use of the extension after changes are posted constitutes acceptance of the updated policy.
